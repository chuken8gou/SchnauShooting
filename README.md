# SchnauShooting

ミニチュアシュナウザーの弾幕シューティングゲーム。

## ゲーム概要

- 縦型の弾幕シューティング
- 主人公はミニチュアシュナウザー（頭にタケコプターをつけて飛行）
- ひたすら敵の弾を避け続けるだけ（自機は弾を撃てない）
- 制限時間を避け続けたらステージクリア
- 全5ステージ

## 操作方法

- **タッチドラッグ**: 自機を移動
- **タップ**: メニュー操作（ステージ開始、次ステージへ）

## 画像アセットの準備

このゲームでは、プレイヤーキャラクター（シュナウザー + タケコプター）の画像が必要です。

### 必要な画像ファイル

以下の4ファイルを `images/` フォルダに配置してください：

```
images/
  ├── player_1.png
  ├── player_2.png
  ├── player_3.png
  └── player_4.png
```

### 画像仕様

- **サイズ**: 64x64px 推奨（レトロ感を維持するため小さめ）
- **フォーマット**: PNG（透過背景）
- **内容**: ミニチュアシュナウザー + タケコプター
- **アニメーション**: 4フレームでタケコプターの回転を表現

### 画像作成例

#### 方法1: 画像生成AIを使用

例えば、以下のようなプロンプトで生成できます：

```
ミニチュアシュナウザー（犬）が頭にタケコプターをつけて飛んでいるイラスト。
64x64ピクセル、8bitゲーム風、透過背景、白と水色をメインカラー。
タケコプターの角度を4段階で変化させた4枚の画像を生成してください。
```

#### 方法2: 手描き・ドット絵エディタ

- [Piskel](https://www.piskelapp.com/) などのドット絵エディタを使用
- 64x64pxのキャンバスでシュナウザーとタケコプターを描画
- タケコプターの角度を4フレーム分作成

#### 方法3: プレースホルダー画像

テスト用に簡易的な画像を作成する場合：
- 64x64pxの白い円や四角形
- 上部に青い線や円（タケコプター部分）

### 画像が無い場合の動作

画像ファイルが見つからない場合、ゲームは白い四角形をフォールバックとして表示します。
動作確認は可能ですが、ビジュアルは簡素になります。

## ゲームシステム

- **ライフ**: 3
- **ヒットボックス**: 半径3px（非常に小さい、弾幕シューティングらしい仕様）
- **グレイズ**: 弾をギリギリで回避するとカウント
- **無敵時間**: 被弾後1.5秒間
- **ランク評価**: S/A/B/C（クリア時のライフとグレイズ数で判定）

## ステージ構成

1. **STAGE 1** (30秒): rain
2. **STAGE 2** (35秒): rain + aimed
3. **STAGE 3** (40秒): rain + aimed + spiral
4. **STAGE 4** (40秒): aimed + spiral + circle
5. **STAGE 5** (45秒): 全パターン

## 弾幕パターン

- **rain**: 上から降ってくる弾
- **aimed**: プレイヤー狙い弾
- **spiral**: 螺旋状に展開
- **circle**: 放射状バースト
